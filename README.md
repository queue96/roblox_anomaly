### 🎬 คัทซีน
- **เปิดคืน:** พี่ชายขี่รถพาผู้เล่นมาตอนเย็น (รถเปลี่ยนตามจำนวนคน: มอไซค์ / ตุ๊กตุ๊ก / เก๋ง / กระบะ) → พี่ชายคุยด้วย → เดินไปดึงเชือกยกแผงร้าน → ขี่ออก → ผู้เล่นเดินเข้าร้าน → ตะวันตกดิน → กลางคืน ไฟดับ
- **จบคืน (ชนะ):** เช้ามืด พี่ชายขี่มารับ → หน้าสรุปผล (ทีม + รายคน: เติมกี่ครั้ง ทำเงิน ไล่ผี ถวาย ค่าเฝ้าร้าน + เวลาที่เฝ้าร้าน + ผีทุกตัวคืนนี้: ไล่ทัน / เติมให้ / ปล่อยไป พร้อมจุดสังเกตของตัวที่พลาด · จอตายก็มีสรุปนี้) → ทุกคนกด "เฝ้าต่ออีกคืน" เพื่อเริ่มคืนใหม่
- **เสียงพากย์อีสานคนจริง:** บทพี่ชายในคัทซีน · ลูกค้าทักทาย/คุย/สั่งน้ำมัน/จ่ายเงิน/เร่ง/เติมผิดตู้/พูดตอนเปิดปิดแผง/ทักคนพนมมือ · รถเครื่องเสียงและรถแห่ · พูดทีละประโยคไม่ทับกัน · **ผู้เล่นไม่มีบทพูด รวมทั้งในคัทซีน** (มีแค่เสียงสวดตอนพนมมือ) · เด็กแว้นไม่พูดและไม่มีซับ · รายการบทที่ต้องพากย์: [assets/sounds/VoiceScript.xlsx](assets/sounds/VoiceScript.xlsx)
- ข้ามได้ (Enter / ปุ่ม B / แตะค้าง) · ระหว่างคัทซีนปุ่มในฉากไม่ขึ้นและเสียงสุ่มรอบทุ่งเงียบ · กล้องเลือกมุมที่ไม่โดนตู้ปั๊ม/เสา/รถบังเอง (`clearCamPos`)

### 🌙 หนึ่งคืนในร้าน (Core Loop)
1. **ไฟดับตอนเริ่ม:** เปิดไฟฉาย [1] → ดึงเชือกเปิดแผงร้าน → ไปสตาร์ท **เครื่องปั่นไฟ** หลังดงกล้วย (มินิเกมวงจังหวะ Space/แตะ ช่วยกันหลายคนได้ พลาด = โดนไฟช็อตกระเด็น)
2. **น้ำมันเริ่มต้นว่าง:** หยิบแกลลอน [3] มุมหลังร้าน → ตักที่ถังหลังร้าน → เทใส่ตู้หน้าร้าน · **ตักจากถังไหนก็ได้ (แดงหรือน้ำเงิน) แล้วเทได้ทั้งตู้ซ้ายและขวา** แต่เทครั้งละ 1 ตู้ (ตู้ซ้ายกับขวาเติมแยกกัน) · เติมให้ลูกค้า 1 ครั้งใช้ 1/4 หลอด หมดก็ต้องไปตักใหม่
3. **แผงน้ำมันขวดหน้าร้าน = ของประกอบฉาก** (ไม่ได้ขาย ไม่มีปุ่มเติม) ว่างตอนเริ่มคืนเหมือนตู้ เทตู้แดงเต็ม = ขวดแดงเต็ม, เทตู้เขียวเต็ม = ขวดเขียวเต็ม
4. **ถวายขนมที่ศาลพระภูมิ:** หยิบขนม [2] ที่ถาดบนเคาน์เตอร์ → ถวาย = คุ้มครอง 150 วิ (แถบเวลามุมขวาบน) มือผีเหี่ยวๆ ยื่นออกมาจากศาลคว้าขนมเข้าไป · ไม่คุ้มครอง = ผีมาบ่อยขึ้น + อาการหลอน (จอเขย่า / เดินช้า / สะดุดล้ม)
5. **ลูกค้ามาทีละคน (ราว 85 วิต่อราย):** รถไทยหลายแบบ + คนเดินเท้าถือแกลลอน/กางร่ม (ชาวบ้านแบบใหม่ สุ่มชุด/ทรงผม/เสียง) ทักทาย สั่ง แล้วตอบราคา → เล่นมินิเกม **เติมน้ำมัน** (กดค้างให้หยุดในขีดทอง) / **เติมลมจักรยาน** (กดตรงจังหวะ 3 ครั้ง) — มือถือขึ้นคำว่า "แตะ / Tap"
6. **ดูผีก่อนเติม:** พนมมือเปิดตาทิพย์ ถ้าเป็นผี ห้ามเติม → ดึงเชือกปิดแผงร้าน (ไม่ได้เงิน แต่นับเป็นผลงานในค่าเฝ้าร้าน) · **ใครอยู่นอกร้านตอนปิดใส่ผี: โดนหลอก ล้ม ตาปรือ ลุกไม่ได้จนผีปั่นป่วนเสร็จ** (เคาะแผง / วิ่งรอบร้าน / ขึ้นหลังคา 14–22 วิ) · เติมให้ผี = เสียงจั๊มสแกร์ `Jumpscare_1/2` · ลูกค้าผีพูดเหมือนคนปกติ ไม่มีป้ายบอกว่าเติมให้ผี
7. เก็บครบ 1200฿ = ชนะทันที (คัทซีนเช้า) · ธูปดับครบ 3 = จอตาย (เริ่มใหม่ / กลับ Lobby)

  - **อยู่ที่ของมัน แล้วเดินมาเมื่อถูกเห็น (ตานี นางรำ แม่นาค กุมารทอง ผีเด็ก ศพห่อผ้า กระสือ ปอบ):** โผล่ที่ดงกล้วย/ต้นไทร/ทุ่ง ไม่มีใครเห็น 30–45 วิ = จางหาย · หันไปเห็น = เดินเข้าหาคนนั้น (เดินหนีได้ แต่ไล่นานสุด 14 วิ)
  - **ไล่ถึงตัว / หนีไม่พ้น / ปิดแผงระหว่างถูกไล่:** ทุกคนที่อยู่นอกร้าน (และคนที่ถูกไล่ถึงตัวในร้านตอนแผงเปิด) โดนหลอก ล้ม ตาปรือ จนผีปั่นป่วนเสร็จ · ปิดแผงแล้วไม่มีใครอยู่นอกร้าน = ผีจางหายไป
  - **เปรต กระหัง (เดินผ่านไกลๆ) และเงาหลังต้นไทร:** จ้องค้าง 2.5 วิ = พุ่งใส่หน้าเฉพาะคนที่จ้อง · **หุ่นไล่กา:** ถูกมองแล้วถอยหนีไปในทุ่ง
  - **มีเสียงตกใจเฉพาะตอนพนมมือจนตาทิพย์เปิดแล้วหันไปเจอ** (ไม่สวดแล้วหันไปเจอ = เงียบ)
- **เสียงสวดตอนพนมมือ:** สวดแบบปกติเสมอ (ไม่มีโหมดสวดเร็วตอนเจอผีแล้ว) ดังขึ้น และ **เพื่อนได้ยินเสียงสวดของเราด้วย** (เสียง 3D ที่หัวคนสวด) · เสียงสวด/วิทยุอยู่ในแถบเสียง "เพลง" ของหน้าตั้งค่า ถ้าปรับเป็น 0 จะไม่ได้ยิน
- **สวดตอนร้านว่างนานๆ** มีโอกาสเรียกผีมาเอง + ลูกค้าคนถัดไปมีโอกาสเป็นผี · ลูกค้าทักคนที่ยืนพนมมือ
