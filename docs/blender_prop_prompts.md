# Prompt ปั้น Prop ด้วย Blender MCP (port 9877)

ใช้คู่กับรูป concept: `assets/map_overview.jpg` (ภาพรวมร้าน) และ `assets/gameplay_anomaly.jpg` (ตู้ปั๊ม/มอเตอร์ไซค์/ป้ายนีออน)
**วิธีใช้:** แนบรูป concept ทั้ง 2 รูปไปในแชท แล้วส่ง **Prompt 0** ก่อน จากนั้นส่งทีละชิ้นตามลำดับ ทำเสร็จทีละชิ้นแล้วเช็กภาพก่อนไปชิ้นถัดไป

ขนาดในแต่ละ prompt อ้างอิงจากของที่ `MapBuilder.luau` วางไว้ในฉากแล้ว เพื่อให้นำเข้า Roblox แล้วเข้าที่เดิมได้พอดี (ตัวละคร Roblox สูงประมาณ 5 studs)

## Prompt 0 — ตั้งค่ากลาง (ส่งครั้งเดียวก่อนเริ่ม)

```
เชื่อมต่อ Blender MCP ที่ localhost:9877 เราจะปั้น prop สำหรับเกม Roblox แนวสยองขวัญชนบทไทย
"ปั๊มหลอด & เพิงปะยางท้ายทุ่ง" ให้หน้าตาใกล้รูป concept ที่แนบมามากที่สุด

สไตล์:
- semi-realistic แบบ stylized ของเก่า ผุพัง สนิมเยอะ เปื้อนโคลนแดงลูกรังที่ขอบล่าง
- โทนสี: สังกะสีสนิมน้ำตาลส้ม, ไม้เก่าสีเทาน้ำตาล, เหล็กทาสีถลอก, โคลนแดง
- สัดส่วนอิงของจริงในชนบทไทยยุค 1980–90
- ทำ bevel เล็กน้อยที่ขอบ ไม่ให้ดูเป็นกล่องเหลี่ยมคม และทำให้ของเบี้ยว/ยุบ/บุบเล็กน้อยให้ดูเก่า

ข้อกำหนดทางเทคนิคสำหรับ Roblox (ต้องทำทุกชิ้น):
1. หน่วย: ใช้เมตร โดย 1 stud = 0.28 m (ขนาดที่ให้ไว้เป็น studs ให้คูณ 0.28)
2. จำนวน polygon: ไม่เกิน 10,000 triangles ต่อ object (Roblox จำกัด 20,000 ต่อ MeshPart)
3. Origin ของ prop อยู่กึ่งกลางฐานล่าง (จุดที่แตะพื้น) แล้ว Apply All Transforms
4. ชิ้นที่ต้องขยับหรือโปร่งใสในเกม ให้แยกเป็น object ต่างหาก และตั้งชื่อตามที่บอกในแต่ละ prompt
5. Material: Roblox อ่าน shader node แบบ procedural ไม่ได้ ถ้าใช้ procedural หรือ Poly Haven
   ให้ UV unwrap แล้ว bake ออกมาเป็นรูป Color / Normal / Roughness / Metalness ขนาด 1024x1024
   (ใช้ texture จาก Poly Haven ได้ ถ้าเปิดใช้ไว้: corrugated metal, rusty metal, old planks, red mud)
6. ห้ามใส่ตัวหนังสือไทยเป็น geometry หรือ texture บนป้าย ให้ทำแผ่นป้ายเปล่า
   เพราะในเกมจะใส่ข้อความผ่าน SurfaceGui เพื่อรองรับ 2 ภาษา TH/EN
7. ไม่ต้องทำไฟจริงใน mesh จุดที่เป็นหลอดไฟ/นีออนให้แยก object ชื่อลงท้าย _Neon
8. เมื่อเสร็จแต่ละชิ้น: ถ่าย viewport screenshot จากมุมเดียวกับ concept ให้ดู
   แล้ว export FBX (Selected Objects, Apply Transform, Forward -Z, Up Y)
   ไปที่ C:\Aunival\pump-lot-anomaly\assets\models\<ชื่อ prop>.fbx
   และเซฟ texture ไว้โฟลเดอร์เดียวกันชื่อ <ชื่อ prop>_Color.png ฯลฯ
9. แต่ละ prop ให้อยู่ใน Collection ของตัวเองชื่อเดียวกับ prop

ตอบรับและรอคำสั่งปั้นชิ้นแรก ยังไม่ต้องปั้นอะไร
```

## ⭐ ชุดที่ 1 — ตัวเด่นใน concept (ทำก่อน)

### 1. GasPump — ตู้ปั๊มน้ำมันหลอดแก้วมือหมุน

```
ปั้น prop ชื่อ "GasPump" ตู้ปั๊มน้ำมันหลอดแก้วมือหมุนแบบปั๊มหลอดชนบทไทย ดูรูป concept ทั้งสองรูป

ขนาดรวม: สูงประมาณ 8 studs, ฐานกว้าง 2.2 x 2.2 studs

โครงสร้างจากล่างขึ้นบน:
- ฐานคอนกรีตเตี้ย 3.8 x 0.5 x 3.8 studs ขอบบิ่น มีคราบโคลนแดงและน้ำมันซึม
- ตัวตู้เหล็กทรงสี่เหลี่ยมสีส้มอิฐซีด สนิมไหลเป็นทาง สีถลอกเห็นเหล็กข้างใน
  หน้าตู้มีแผ่นป้ายเปล่าสีครีมเหลือง (สำหรับข้อความ "ปั๊มหลอด แก๊สโซฮอล์ 91 ราคา/ลิตร")
  ขอบป้ายเป็นสนิม มีน็อตยึด 4 มุม
- ข้างตู้มีมือหมุนเหล็กสีดำ (แยก object ชื่อ "HandCrank" pivot อยู่ที่แกนหมุน)
- สายน้ำมันยางดำขดห้อยจากข้างตู้ ปลายเป็นหัวจ่ายเหล็ก (แยก object ชื่อ "Nozzle")
- กระบอกแก้วใสทรงกระบอกตั้ง สูง 2.8 studs เส้นผ่านศูนย์กลาง 1.65 studs
  มีเส้นขีดบอกระดับลิตรสีขาวรอบแก้ว (แยก object ชื่อ "GlassTube")
- น้ำมันสีส้มอำพันในกระบอก เป็นทรงกระบอกเล็กกว่าแก้วนิดหน่อย
  pivot อยู่ที่ก้นกระบอก เพื่อให้ scale แกน Y ทำระดับน้ำมันขึ้นลงได้ (แยก object ชื่อ "FuelLiquid")
- ฝาครอบบนเป็นทรงโดมเตี้ยหรือหมวกเหล็กสีแดงสนิม และมีหน้าปัดกลมเล็กแบบ concept รูปที่ 2
- โครงเหล็ก 4 เสาเล็กยึดระหว่างตัวตู้กับฝาบน ล้อมกระบอกแก้ว

รายละเอียดความเก่า: ขอบล่างตู้เปื้อนโคลนแดง, สติกเกอร์ลอก, คราบน้ำมันไหลจากหัวจ่าย
```

### 2. AirCompressor — ถังปั๊มลมปะยาง

```
ปั้น prop ชื่อ "AirCompressor" ถังปั๊มลมของร้านปะยางชนบท ตามที่วางอยู่หน้าเพิงในรูป concept

- ถังลมทรงกระบอกนอน ยาว 4.2 studs เส้นผ่านศูนย์กลาง 2.1 studs
  สีน้ำเงินเข้มอมเทาซีด สีถลอก สนิมเป็นดวง ขอบโค้งปลายถังทั้งสองด้าน
- ขาตั้งเหล็ก 4 ขาพร้อมล้อเหล็กเล็ก 2 ล้อด้านหนึ่ง
- บนถังมีมอเตอร์สีดำ, ล้อสายพาน, ฝาครอบสายพานตะแกรง
- เกจวัดลมหน้าปัดกลม (แยก object ชื่อ "PressureGauge_Needle" สำหรับเข็ม)
- วาล์วหมุนสีแดง (แยก object ชื่อ "ReliefValve" pivot ที่แกน ใช้ตอนผีถังลมคลั่ง)
- สายลมยางสีดำขดเป็นวงห้อยข้างถัง ปลายมีหัวเติมลม
- เปื้อนโคลนแดงที่ล้อและขาตั้ง
```

### 3. TireStack — กองยางเก่า

```
ปั้น prop ชื่อ "TireStack" กองยางรถเก่าแบบที่วางหน้าตู้ปั๊มในรูป concept

ทำ 3 แบบแยก object ในไฟล์เดียว:

- "TireLeaning": ยางเส้นเดียวตั้งพิงอะไรสักอย่าง เอียง 15 องศา
- "TireWithRim": ยางพร้อมกระทะล้อเหล็กสนิม วางนอน

ยางเส้นผ่านศูนย์กลางประมาณ 2.4 studs หนา 0.7 studs ดอกยางสึกเห็นร่อง
ยางสีดำซีดเทา มีฝุ่นและโคลนแดงเกาะ ใช้ polygon น้อย แต่ normal map มีลายดอกยาง
```

- นำเข้าด้วย **3D Importer** (File → Import 3D) ทีละไฟล์ `.fbx`
