🏗️ Phase 1: ปั้น Map, วางโมเดล & จัดแสงชนบท (ยังไม่ต้องเขียนโค้ด)

เป้าหมายของเฟสนี้คือการสร้างบรรยากาศ **"ปั๊มหลอดท้ายทุ่ง"** ใน Roblox Studio ให้เดินสำรวจได้จริง และจัดกลุ่มโมเดลใส่ Folder ให้พร้อมสำหรับเขียนโค้ดในเฟสถัดไป (คลิกติ๊กถูกเมื่อทำเสร็จแต่ละข้อ):

✓
1. สร้างพื้นถนนดินลูกรัง & ลานหน้าเพิง (120 x 120 Studs)
ปรับ Material พื้นเป็น Mud หรือ Ground สีดินแดง พร้อมตั้งค่า Anchor = true ทุกชิ้น
✓
2. สร้างเพิงสังกะสีไม้ไผ่ & โต๊ะไม้เก็บเงิน
ตัวเพิงขนาดประมาณ 35 x 22 Studs มีหลังคาสังกะสีกันฝน และมีจุดเกิดผู้เล่น (SpawnLocation) ข้างในเพิง
✓
3. วางอุปกรณ์ทำงานหลักหน้าร้าน & บนโต๊ะ
วางตู้ปั๊มน้ำมันหลอดแก้ว (GasPump), ถังปั๊มลม (AirCompressor), กระป๋องเงิน (MoneyTin), วิทยุ (Radio), และแผ่นสังกะสีปิดร้าน (ShutterDoor)
✓
4. วางศาลพระภูมิไม้เก่า + ธูป 3 ดอก (ข้างเพิงฝั่งซ้าย)
สร้างธูป 3 ดอกตั้งชื่อ Incense1, Incense2, Incense3 ใส่ ParticleEmitter ควันธูปและไฟสีแดง
✓
5. ตกแต่งทุ่งนา หุ่นไล่กา & ดงกล้วยตานีหลังร้าน
ฝั่งตรงข้ามถนนเป็นทุ่งนา + หุ่นไล่กา (Scarecrow) ส่วนหลังร้านและข้างขวาเป็นดงกล้วยตานี + เครื่องปั่นไฟ (Generator)
✓
6. วาง 5 จุด Prop Hooks เผื่ออัปเดตระยะยาว
วางทิ้งไว้ตั้งแต่วันแรก: (1) กระจกเงาข้างฝา, (2) รูปขาวดำตาเจ้าของอู่ & ปฏิทิน, (3) สวิตช์คัตเอาต์ไฟ, (4) ถังน้ำแข็ง, (5) ห้องน้ำสังกะสีท้ายดงกล้วย
✓
7. วาง Part จุดวิ่งของรถ 3 จุด & ตั้งค่าแสงกลางคืน (Lighting)
วาง Part ใส 3 อันบนถนน (SpawnPoint, StopPoint, ExitPoint) และปรับค่า Lighting ตามตารางด้านขวา
✓
8. 🌐 ทำป้ายร้านและของตกแต่งแบบ 2 ภาษา (TH / EN Visual Cue)
เขียนป้ายหน้าร้านเป็นไทยคู่กับอังกฤษ เช่น 'ปั๊มหลอดท้ายทุ่ง - RURAL GAS & TIRE' เพื่อให้ผู้เล่นต่างชาติเข้าใจบริบทร้านทันที

🛵 Phase 2: เตรียมโมเดลรถลูกค้า & จุดซ่อนผี (ใน ServerStorage)

แทนที่จะสร้างรถแยกเป็น 20 คัน เราใช้เทคนิค **"โมเดลรถแม่แบบคันเดียว (Master Vehicle Template)"** ที่มีทั้งคนขับปกติและชิ้นส่วนผีซ่อนไว้ (`Transparency = 1`) เวลาเสกรถออกมา โค้ดแค่สั่งเปิดชิ้นส่วนผีที่ต้องการ!

✓
1. สร้างโฟลเดอร์ VehicleTemplates ใน ServerStorage
เก็บโมเดลรถต้นแบบไว้ใน ServerStorage เพื่อรอให้สคริปต์ Clone() ออกมาวิ่งบนถนน
✓
2. ตั้งค่า PrimaryPart ของโมเดลรถมอเตอร์ไซค์
สร้าง Part แกนกลางรถชื่อ Chassis แล้วตั้งเป็น PrimaryPart ของ Model เพื่อให้สั่งเลื่อนรถทั้งคันด้วยคำสั่งเดียวได้
✓
3. วางโมเดลคนขับ (DriverNPC) บนเบาะหน้า
มีชิ้นส่วน Head, Torso, Legs ครบ เพื่อรอให้โค้ดสั่งหมุนคอ 180 องศา หรือซ่อนขากลายเป็นไส้กระสือ
✓
4. วางโมเดลผีคนซ้อนท้าย (GhostPassenger) ซ่อนไว้บนเบาะหลัง
วางโมเดลผู้หญิงชุดไทยไร้หัวซ้อนท้ายไว้เลย แต่ตั้งค่า Transparency = 1 (ล่องหนไว้ในตอนปกติ)
✓
5. 🌐 สร้างป้ายทะเบียน (LicensePlate) รองรับผู้เล่นต่างชาติ
ป้ายปกติใช้พื้นขาวตัวดำ แต่ป้ายผีให้เปลี่ยนเป็นพื้นดำเปื้อนเลือด + ตัวเลขสีแดงเรืองแสง '4444 CEMETERY / ป่าช้า' เพื่อให้คนอ่านไทยไม่ออกก็รู้ว่าผิดปกติ!

⚙️ Phase 3: เขียนโค้ด Core Loop (รถเข้าจอด, เติมน้ำมัน, ปิดร้าน, นับเงิน)

เมื่อปั้นแมพและเตรียมโมเดลรถใน Phase 1–2 เสร็จแล้ว เฟสนี้เราจะเริ่มเขียนสคริปต์หลัก `GameManager.server.luau` เพื่อให้ตัวเกมเล่นได้ตั้งแต่ต้นจนจบ:

✓
1. ใส่ ProximityPrompt ที่ตู้ปั๊มหลอด และ เชือกปิดร้าน
ตู้ปั๊มน้ำมันตั้ง HoldDuration = 3 วินาที (กดค้างหมุนปั๊ม) ส่วนเชือกปิดร้านตั้ง HoldDuration = 0.5 วินาที
✓
2. เขียนระบบเสกรถวิ่งจาก SpawnPoint มาจอดที่ StopPoint
ใช้ TweenService หรือ CFrame Lerp เลื่อนรถมาจอดหน้าเพิง พร้อมล็อกปุ่ม 3 วินาทีแรกให้คนส่องไฟฉายดู
✓
3. เขียนฟังก์ชันตรวจคำตอบ (เติมน้ำมัน vs ดึงแผงปิดร้าน)
เช็คตัวแปร currentVehicleIsAnomaly ว่าผู้เล่นตัดสินใจถูกหรือผิด
✓
4. ระบบอัปเดตเงินในกระป๋อง (เป้าหมาย 500฿) & ธูปศาลพระภูมิ 3 ดอก
ทำถูกบวกเงิน (+100฿ / +50฿) พอครบ 500฿ ชนะ / ถ้าเผลอเติมให้ผีสั่งดับควันธูปทีละดอก
✓
5. 🌐 สร้างโมดูลแปลภาษาคำพูดลูกค้า (LanguageModule.luau - TH/EN)
เก็บประโยคพูดของลูกค้าและชื่อผีเป็น 2 ภาษา (TH / EN) เช็คค่า Player.LocaleId เพื่อให้คนไทยอ่านภาษาไทย ต่างชาติอ่านภาษาอังกฤษอัตโนมัติ

👻 Phase 4: เขียนโค้ดระบบสุ่มผี (AnomalyManager) & ไฟฉาย

แยกโค้ดเสกความผิดปกติออกมาเป็น `ModuleScript` เพื่อให้คุณสามารถเพิ่มผีจาก 5 แบบ เป็น 30 แบบในอนาคตได้ง่ายๆ โดยไม่ต้องแก้โค้ดลูปหลัก:

✓
1. สร้างไอเทมไฟฉายกบ (Flashlight Tool) แจกเข้า StarterPack
ผู้เล่นทุกคนเกิดมาพร้อมไฟฉาย กดคลิกเพื่อเปิด/ปิด SpotLight ส่องดูคนขับและดงกล้วย
✓
2. เขียนโมดูล AnomalyManager.luau (ชุดแรก 5–10 รูปแบบ)
สุ่มเปิดผีคนซ้อนไร้หัว, เปลี่ยนป้ายทะเบียน 4444, เปลี่ยนเสียงวิทยุเป็นพระสวด, โผล่ผีตานีหลังดงกล้วย, หมุนคอคนขับ 180 องศา
✓
3. เขียนฟังก์ชัน ResetAnomalies() ตอนรถขับออกไป
คืนค่าวิทยุ หุ่นไล่กา และดงกล้วยให้กลับเป็นปกติทุกครั้งก่อนรถคันต่อไปจะเข้ามา
✓
4. ใส่สคริปต์ไฟนีออนหน้าร้านกะพริบ & เสียงบรรยากาศทุ่งนา
ใส่เสียงจิ้งหรีด เสียงหมาหอน และสคริปต์สุ่มกระพริบหลอดไฟนีออนหน้าเพิง

🧩 ตัวอย่างการออกแบบตาราง Anomaly ในโค้ด

โค้ดจะถูกออกแบบให้เพิ่มผีใหม่ได้ง่ายๆ แค่เพิ่มรายการลงใน Table แบบนี้:

  end,

  end
}
