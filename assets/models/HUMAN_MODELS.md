# ตัวละครมนุษย์ low-poly — สรุปแนวคิดการปั้น

ตัวละครมนุษย์ทั้งหมด **สร้างด้วยสคริปต์ Python ใน Blender** ไม่ได้ปั้นด้วยมือ
(วิธีทำงานต่อ / วิธีตรวจ / ปัญหาที่เคยเจอ: ดู `HUMAN_PIPELINE_GUIDE.md`)
แก้ตัวเลขในสคริปต์แล้วรันใหม่ จะได้โมเดลชุดเดิมกลับมาทุกครั้ง
ผมสร้างด้วยสคริปต์ `build_hair.py` เป็น object แยกชื่อ `Hair_<ทรง>` ผูกกับกระดูก `head` (ดูหัวข้อ 6)
ผิว หน้าตา และริ้วรอย เป็น texture ที่วาดด้วยสคริปต์ `build_skin.py` (ดูหัวข้อ 7)
เสื้อผ้าไทยบ้านสร้างด้วยสคริปต์ `build_clothes.py` เป็น object `Cloth_<ชุด>*` (ดูหัวข้อ 8)
ท่าทาง (ยืน เดิน วิ่ง ผี) และการ export เข้า Roblox อยู่ใน `build_anims.py` (ดูหัวข้อ 9)

## หลักการปั้น

### 1. ผิวชิ้นเดียว สร้างจาก "วงแหวน" หน้าตัด
- ลำตัว คอ และหัว สร้างจากวงแหวน 16 จุดเรียงตามความสูง
  แต่ละวงกำหนดความกว้าง ความหนาด้านหน้า และความหนาด้านหลัง (`sring(z, กว้าง, หน้า, หลัง)`)
- แขน 10 จุดต่อวง ขา 10 จุดต่อวง เท้า 12 จุดต่อวง นิ้วมือและนิ้วเท้า 4 จุดต่อวง
- วงแหวนแต่ละชั้นต่อกันเป็น quad รอยต่อจึงไล่ระดับต่อเนื่อง ไม่เป็นข้อต่อแบบหุ่นของเล่น
- จมูกกับหูเป็นชิ้นปิดแยก ผูกแข็งกับกระดูก `head`
- ใช้ smooth shading ได้ประมาณ 1,000–1,200 faces ต่อตัว

### 2. จุดเชื่อมที่ต้องระวัง
- **ไหล่:** แขนออกจากลำตัวเกือบแนวนอนก่อน แล้วค่อยโค้งลงเป็นมุม 42°
  กล้ามไหล่จึงครอบหัวไหล่ รูต่อแขนต้องเกือบจัตุรัส ขนาดพอดีกับแขน
- **บ่า:** ลาดเป็นเส้นตรงจากข้างคอลงถึงปลายไหล่ (ยกเฉพาะด้านข้างและด้านหลัง ด้านหน้าไม่ยก)
- **คอด้านหลัง:** ท้ายทอยยื่น ร่องคอเว้าเข้า แล้วแผ่ออกเป็นบ่า (ทรง S อ่อนๆ)
- **ขอบกราม:** ลาดจากคางขึ้นไปหลังหู ไม่เป็นแนวราบรอบคอ

### 3. Rig มาตรฐานเดียวกันทุกตัว (52 bones)
- กระดูกหลัก: `root`, `hips`, `spine`, `chest`, `neck`, `head`
- ซ้าย/ขวา (`.L` / `.R`): `shoulder`, `upper_arm`, `forearm`, `hand`, นิ้วละ 3 ข้อ (`index_01`–`03`, `middle`, `ring`, `pinky`, `thumb`), `thigh`, `shin`, `foot`, `toe`
- ชื่อกระดูกเหมือนกันทุกตัว animation จึงใช้ข้ามตัวได้ (ควร retarget เพราะสัดส่วนต่างกัน)
- ผูก skin ด้วย Automatic Weights แล้วปรับเพิ่มดังนี้:
  - เกลี่ย weight ที่ไหล่ สะโพก รักแร้ เข่า และศอก
  - กล้ามไหล่ไล่ weight จาก `shoulder` ไป `upper_arm` เวลาเอาแขนลงไหล่จะโค้งมน
  - เนื้อก้นผูกกับ `hips` เป็นหลัก ตอนนั่งก้นจะไม่ยุบ
  - เปิด Preserve Volume (dual quaternion) ข้อพับจะไม่ยุบ

### 4. สร้างตัวใหม่จากตัวที่มีอยู่ ด้วยการดัดตัว + กระดูกพร้อมกัน
หลังผูก skin แล้ว ย้ายจุดของ mesh และกระดูกด้วยฟังก์ชันเดียวกัน weight จึงยังถูกต้อง ไม่ต้องผูกใหม่
- **หญิง:** ปั้นใหม่จากสคริปต์ชาย แล้วย่อทั้งตัว ×0.93
  - หญิงชาวบ้านไม่มีกล้าม: ไหล่ลาด ไม่มีหัวไหล่นูน ต้นแขนเรียวลงถึงศอก ปลายแขนไม่มีกล้าม (`build_body_female.py` แหวน `AR`)
- **เด็ก:** ปั้นในสัดส่วนผู้ใหญ่ แล้วรัน `child_remap.py` ขยายหัว ×1.4 ลดหัวลง (คอสั้น) หดขา และย่อเหลือ 1.15 ม.
- **คนชรา:** ปั้นตัวผอม/หย่อน แล้วรัน `elder_posture.py` ให้หลังค่อม (`KYPHO`) ห่อไหล่ (`SHOULDER_FWD`) และเตี้ยลง
- **ผอม/อ้วน:** รัน `body_type.py` ดันผิวแต่ละจุดเข้า/ออกจากกระดูกที่ขยับมันอยู่ ตามตารางตัวคูณของแต่ละกระดูก (ด้านข้าง, หน้า, หลัง)
  - **ผอมโซ:** แขนขาเหลือราวครึ่งหนึ่ง แต่ข้อต่อยังใหญ่ (เข่า/ศอกเป็นปุ่ม) ท้องแฟบ คอลีบ แก้มตอบ
  - **หญิงผอม:** ผอมเรียว ไม่ใช่ผอมโซ: ลดเท่าๆ กันทั้งตัว ข้อต่อไม่เป็นปุ่ม แก้มไม่ตอบ (`TYPE_SHAPE[("female", "thin")]`: `KNOBBY`, `GAUNT`)
  - **หญิงอ้วน / หญิงชราอ้วน:** อ้วนย้วย (ชาวบ้านไม่ได้ออกกำลังกาย): พุงย้อยมากขึ้น (`BELLY`) ต้นแขนห้อยด้านล่าง (`ARM_SAG`)
  - **อ้วน:** แขนขาหนา เหนียง ยืนกางขาเล็กน้อย
    - พุงย้อยลงคลุมหัวหน่าว (`belly_sag`)
    - เกลี่ยขาให้ตรงไม่โก่ง และน่องเรียวลงเข้าข้อเท้า (`straighten_legs`)
    - เกลี่ยรักแร้กับฐานคอ (`round_armpits`)
- **หญิงตั้งครรภ์:** รัน `pregnancy.py` บนตัวหญิงปกติ ให้ท้องนูนทรงวงรีสูงด้านหน้าและเต็มออกด้านข้าง โดยไม่เพิ่มขนาดแขนขาหรือทำให้ท้องย้อย

### 5. ไม่ให้ร่างกายทะลุกัน
- ทุกข้อต่อมีช่วงหมุนจำกัด (Limit Rotation, `add_joint_limits.py`) เช่น เข่างอได้ 95° ศอกงอได้ 120° นิ้วงอกลับหลังไม่ได้
- เกณฑ์: ผิวเบียดกันได้ไม่เกิน 1.5 ซม. (หนังเบียดกัน) ถ้าลึกกว่านั้นนับว่าทะลุ
- ค่าช่วงหมุนหาจากการหมุนทีละ 5° จนเจอจุดที่เริ่มทะลุ (`search_joint_limits.py`)
- ตัวที่สัดส่วนต่างออกไป (เด็ก หญิงชรา ชายชรา ตัวอ้วน) มีค่าจำกัดเฉพาะตัวเพิ่ม
- `test_self_intersection.py` ทดสอบ 21 ท่า
  - ผ่านทั้งหมด ยกเว้นท่าที่ใช้แขนสองข้างพร้อมกัน (กอดตัวเอง หรือเอามือแตะหน้า)
  - ข้อจำกัดรายข้อต่อกันกรณีนี้ไม่ได้ ให้ตรวจ animation ด้วย `check_animation.py`

## ลำดับการสร้าง (pipeline)

```
ปั้นตัว (build_body_*.py)
 → สร้าง rig + ผูก weight (build_rig_*.py)
 → [เด็ก] child_remap.py   [คนชรา] elder_posture.py
 → [ผอม/อ้วน] body_type.py
 → armpit_weights.py → smooth_junctions.py (เกลี่ยคอ ท้ายทอย รอยต่อ)
 → add_joint_limits.py (+ ค่าจำกัดเฉพาะตัว)
 → test_self_intersection.py → build_hair.py (ทรงผม) → build_skin.py (UV + material ผิว) → build_clothes.py (เสื้อผ้า) → build_anims.py (weight ≤ 4 กระดูก + ท่าทาง) → เซฟ .blend
```

## 6. ทรงผม (`human_base/build_hair.py`)

ทรงผมทุกแบบสร้างจากหัวของตัวละครแต่ละตัวเอง: ยิงรังสีจากกลางหัวออกไปวัดระยะถึงหนังศีรษะ
แล้วดันผมออกตามความหนาที่กำหนด ตัวเลขชุดเดียวจึงใช้ได้กับหัวเด็ก (ใหญ่ ×1.4) ผู้ใหญ่ คนชรา (หัวก้ม) และหน้าอ้วน/ผอม
ค่าความยาวทั้งหมดคูณขนาดหัว `s` (ชายผู้ใหญ่ = 1)

- **มุม:** `th` = รอบหัว (0 = หน้า, 90 = ซ้ายของตัวละคร, 180 = หลังหัว), `ph` = มุมเงย (90 = กลางกระหม่อม)
- **`shell`:** ผมคลุมหนังศีรษะจนถึงแนวไรผม ถ้ามี `hem` ผมจะตกตรงลงตามแรงโน้มถ่วงถึงระดับนั้น แล้วพับกลับด้านในและเก็บปลายเข้าหนังศีรษะ
  ส่วนที่ตกลงมาจะถูกดันให้พ้นตัว (`clear`) แล้วเกลี่ยให้เรียบ จึงพาดบ่าและหน้าอกได้โดยไม่ทะลุ
- **`tube` / `ball` / `ring`:** หางม้า แกละ เปีย จุก โบว์ หนวด คิ้ว และห่วงทอง
- **ผมผี:** ทุกทรงแหวกตรงหน้าให้เห็นตาซ้าย (`GHOST_GAP` = ตำแหน่ง, ความกว้าง หน่วยองศา)
  ความยาวถึงเข่าและลากดินวัดจากพื้นใต้เท้า (`_height`) ผมลากดินแผ่ไปด้านหลังบนพื้น ทรงยาวใช้แนวผมถี่ขึ้น (ทุก 10°)
  และเกลี่ยแนวผมข้างเคียงเข้าหากัน (`xrelax`) จุดที่จมในตัวต่ำกว่าสะโพกจะถูกดันออกตามทิศที่ผมห้อย ไม่ใช่ไปผิวที่ใกล้ที่สุด
  (ไม่อย่างนั้นผมจะไปติดอยู่ระหว่างขา) ทรงยุ่งใช้ปลายผมหยักแรง (`jitter_f`) มีช่อผมชี้ออกแล้วห้อยลง และมีเส้นผมห้อยปิดหน้า
- **ผูกกับลำตัว (`bind_to_body`, ทรงใน `BODY_BOUND` คือผมผี long / knee / floor):** ไล่ weight ตามความสูงจากตำแหน่งข้อต่อของ rig
  ส่วนเหนือฐานกะโหลกตาม `head` แล้วไล่ลงไปเป็น `neck` → `chest` → `spine` → `hips` เวลาหันหัว ผมที่ปิดหน้าจะหันตาม
  แต่ผมช่วงใต้บ่าจะอยู่กับลำตัว ไม่สะบัดทั้งแผง เปิด Preserve Volume เหมือนตัว
- ผมบางที่สุดหนา 6–8 มม. ถ้าบางกว่านี้หนังศีรษะ low-poly จะโผล่ทะลุผม

| ตัวละคร | ทรง (ตัวแรก = ที่เปิดไว้) |
|---|---|
| ชาย | `student` ทรงนักเรียน, `rong_song_sung` รองทรงสูง, `side_part` รองทรงต่ำปัดข้าง |


**ข้อจำกัดที่ยังเหลือ**
- ผมของชายชราและหางม้ายังผูกกับ `head` ทั้งชิ้น เวลาหันหัวมากๆ ปลายผมอาจทะลุบ่า
- ยังไม่มีกระดูกผม ถ้าต้องการให้ผมแกว่ง ต้องเพิ่ม (`hair_01`–`03`) แล้วไล่ weight
- ผมผียาวคลุมหน้าขา เวลาเดินก้าวยาวขาอาจทะลุผม (ผมตามสะโพก ไม่ตามขา)
- ทรงผียาวถึงเข่าและลากดินมีประมาณ 3,400–4,100 faces (7–8 พัน triangles) ยังต่ำกว่าเพดาน MeshPart ของ Roblox แต่ควรใช้เฉพาะตอนเกิด anomaly
- ช่องแหวกของผมผียาวลงไปตลอดความยาวผม (ผมทุกเส้นตกตรงจากแนวไรผม จึงปิดกลับใต้คางไม่ได้)
- ผมยาวของชายชรามีเส้นผมด้านข้างห้อยลงมาเป็นแผ่นบางๆ

## 7. ผิว หน้าตา และริ้วรอย (`human_base/build_skin.py`)

หัวมี faces น้อย (วงแหวน 16 จุด) จึงไม่ได้ปั้นตา ปาก หรือรอยย่นลงไปในตัวโมเดล
แต่วาดเป็น texture 1024 แทน ทั้งภาพสี และ normal map ที่ทำให้ร่องรอยย่นมีเงาเวลาโดนแสง
- **texture ชุดเดียวต่อตัวละคร:** ตัวผอม อ้วน และท้องมี topology เดียวกับตัวปกติ (จำนวนจุดและลำดับ loop ตรงกัน)
  จึงกาง UV บนตัวปกติครั้งเดียว เก็บไว้ใน `<ชื่อ>_uv.json` แล้วใช้ UV นี้กับทุกรูปร่าง
- **UV (v ขึ้นบน):**
  - ครึ่งบน = หัวและคอ กางแบบทรงกระบอกรอบแกนกระดูก `head` โดย u = มุมรอบหัว (หน้าอยู่ตรงกลาง, รอยต่ออยู่ท้ายทอยซึ่งผมบังอยู่) และ v = ความสูงตามแกนหัว
    ใช้สูตร u = a + 0.6·sin(a) (`K_FACE`) ให้หน้าได้ pixel มากกว่าท้ายทอย 1.6 เท่า
    หัวคนชราที่ก้มก็ใช้ได้ เพราะวัดมุมตามแกนหัว ไม่ใช่แกนโลก
  - ซ้ายล่าง = ลำตัว แขน ขา (smart project)
  - ขวาล่าง = มือและเท้า (smart project, ได้ pixel มากกว่าเพื่อให้เห็นข้อนิ้วและเล็บ)
- **ตำแหน่งหน้า:** วัดจากชิ้นจมูกของตัวละครนั้นเอง (ยอดจมูก, ปลายจมูก, ฐานจมูก, ปีกจมูก) และคางที่ต่ำสุด
  ระดับตา = ยอดจมูกลงมา 22% ของความยาวจมูก, ระดับปาก = ฐานจมูกลงไป 40% ของระยะถึงคาง ขนาดทุกอย่างคูณด้วยขนาดหัว `s`
- **วาดอะไรบ้าง:**
  - หน้า: ตา (ตาขาว ม่านตา รูม่านตา แสงสะท้อน), ขนตาบน, รอยพับเปลือกตา, คิ้วเป็นเส้นขน, รูจมูก, ริมฝีปาก, แก้มแดงเรื่อ, เบ้าตาสีเข้มขึ้นเล็กน้อย
  - ริ้วรอยตามค่า `age` (เด็ก 0, ผู้ใหญ่ 0.2–0.3, คนชรา 0.9–1.0):
    - ผู้ใหญ่: ร่องแก้มข้างจมูกบางๆ และรอยหน้าผาก 2 เส้น
    - คนชรา: รอยหน้าผาก 4 เส้น, ตีนกา, ถุงใต้ตา, รอยขมวดคิ้ว, ร่องจากมุมปากลงคาง, รอยย่นรอบปาก, รอยย่นที่คอ, ตกกระที่หน้าและหลังมือ, เส้นเลือดหลังมือ
  - ตัว: ข้อนิ้ว (ปุ่มนูนและรอยย่น), รอยข้อมือ, เล็บมือ/เล็บเท้า, รอยพับที่ข้อศอกและเข่า, ฝ่าเท้าสีอ่อนกว่า
- **ผี (`_Ghost_*`):** ผิวซีดเทาอมเขียว, เบ้าตาลึกและคล้ำ, ตาเหลือก (ม่านตาสีซีดเลื่อนขึ้นไปใต้เปลือกตา, ตาแดงเป็นเส้นเลือด), คราบดำไหลลงจากตา,
  ปากคล้ำแตก, แก้มตอบ, เส้นเลือดม่วงที่ขมับ คอ และแขน
- **ผีหนังเหี่ยว (`_Withered_*`):** ใช้กับผีที่ดัดแปลงจากโมเดลคน (UV เดิม) หนังแห้งสีเทาอมน้ำตาลเหมือนศพแห้ง ย่นทั้งตัว (รอยย่นแบบคนชราทุกเส้น + รอยพับหนังใหญ่ + ลายแตกละเอียด),
  รอยแตกแดงคล้ำ, ปื้นช้ำน้ำตาลและม่วง, แผลเปิดเปียก, เบ้าตาลึกถึงกะโหลก, ตาขุ่นขาว (ต้อ), ปากหดจนเห็นฟันเหลืองยาว,
  ขมับและแก้มยุบ โหนกแก้มกับกรามโผล่ เอ็นคอนูน, ซี่โครงและกระดูกอกบนลำตัว, เอ็นหลังมือ, เล็บยาวหนาสีเหลืองน้ำตาล (ฟังก์ชัน `wither()`)
- **ไฟล์ของแต่ละตัว** (อยู่ข้าง .blend): `<ชื่อ>_Color.png`, `_Normal.png` (แบบ OpenGL, +Y ขึ้น ซึ่ง Roblox ใช้), `_Roughness.png`
  ชุดผี `<ชื่อ>_Ghost_Color.png`, `_Ghost_Normal.png`, `_Ghost_Roughness.png` และชุดหนังเหี่ยว `<ชื่อ>_Withered_Color.png`, `_Withered_Normal.png`, `_Withered_Roughness.png`
- **ใน .blend:** Body ใช้ material `Skin` ส่วน `SkinGhost` และ `SkinWithered` เก็บไว้ (fake user) สำหรับสลับ
  ใน Roblox ให้ใส่เป็น `SurfaceAppearance` (ColorMap / NormalMap / RoughnessMap) แล้วสลับเป็นชุด Ghost ตอนเกิด anomaly
- รูปตัวอย่าง (แถวบน = คน, แถวกลาง = ผี, แถวล่าง = ผีหนังเหี่ยว; หน้าตรง, เฉียง, ข้าง, มือ) อยู่ใน `skin_previews/`

```python

```

**ข้อจำกัดที่ยังเหลือ**
- หน้าขยับไม่ได้ (ไม่ใช่ Dynamic Head / FACS) ถ้าต้องการเปลี่ยนสีหน้า ให้ทำ texture เพิ่มแล้วสลับ
- ถ้าแก้ topology ของ Body (เพิ่มหรือลบจุด) ต้องรัน `skin_all()` ใหม่ เพราะ `add_skin` ตรวจจำนวน loop แล้วจะหยุดถ้าไม่ตรงกับ `_uv.json`
- ตัวอ้วนใช้ UV ของตัวปกติ texture จึงยืดออกเล็กน้อยตรงท้องและต้นขา
- รอยต่อ UV ที่ท้ายทอยและที่คอ (ระหว่างครึ่งบนกับครึ่งล่าง) อาจเห็นเส้นจางๆ ถ้าส่องใกล้มาก
- ใบหูได้ texture เดียวกับผิวด้านหลังหู (ฉายจากทรงกระบอก) ซึ่งเป็นสีผิวเรียบอยู่แล้ว

- `ghost_sabai_cream_blood` ไม่วนลาย: สไบใส่ `span=True` ให้ u เป็น 0..1 ตลอดความยาวผ้า เลือดจึงอยู่ที่ปลายผ้าบนบ่าเสมอ

- ชิ้นแบบใหม่ที่ทำมาพร้อมชุดผี:
  - `sweep` ชิ้นแข็งทรงเลนส์/เขาตามเส้นทาง (หัวเข็มขัด ทับทรวง), `crown` ชฎาแบบ lathe รอบหัวและผมที่แสดงอยู่ ลงคลุมถึงท้ายทอย, `flowers` ดอกไม้ทัดหู + อุบะ (ทั้งสองผูกกับ `head`)
  - strip: `over=True` วางทับทุกชิ้นที่สร้างก่อนหน้า (ยิง ray ออกจากผิวผ่านทุกชั้นแล้ววางเลยชั้นนอกสุด) เช่น สไบทับเสื้อ ซิ่น เข็มขัด กรองคอ,
    `cols=N` จุดข้ามความกว้างแถบ N จุด (แถบกว้างจะไม่ตัดผ่านขอบชิ้นข้างใต้), `tail_hang=True` ชายผ้าที่ต่ำกว่าเอวห้อยจากสะโพก ไม่ตามขา, `span=True` ใช้ได้กับ tube ด้วย (u 0..1 รอบเอว ด้านหน้า = 0)
  - tube: `seated=True` ผ้าซิ่นสำหรับท่านั่ง (หน้าและหลังตามต้นขาตั้งแต่เอว ด้านหลังเผื่อที่ให้ก้นและต้นขา) ใช้เฉพาะในไฟล์ผีที่นั่ง
  - ring: `t` ตำแหน่งตามกระดูก (ทองต้นแขน), `tr` ความหนา, `room` ระยะห่างจากผิว · shell: `chest_wrap()` ไม่เผื่อที่รักแร้ (จะโป่งเข้าสไบ)

รองเท้า: ชุดชาวบ้านใส่รองเท้าแตะ (`mohom`, `sarong`, `blouse_sin`, `indigo_scarf`, `sabai`, `chest_wrap`, `chong_gold`, `mohom_child`), `red_shirt` และสายแว้นใส่ผ้าใบ, `farmer` ใส่บูท

**3 วิธีสร้างชิ้นผ้า**
- **shell** (เสื้อ กางเกง โจงกระเบน ผ้าแถบ บูท): ยก faces ของ Body ขึ้นมาแล้วดันออกตาม normal 4–30 มม. แล้วพับขอบเข้าหาผิว
  - ได้ UV และ weight ของตัวมาด้วย ผ้าจึงงอตามตัวพอดี
  - texture ของ shell ใช้ชุดละ 1 ชุด วาดลงใน UV ของตัว (สีผ้า ลายทอ รอยยับ กระดุม กระเป๋า คอวี ตะเข็บยีนส์)
  - เลือก faces ด้วยส่วนของตัว (`torso`, `arm`, `leg`, `foot`) และตำแหน่งตามแนวกระดูก: แขน 1 = ศอก, 2 = ข้อมือ; ขา 1 = เข่า, 2 = ข้อเท้า; ลำตัว `tz` 0 = สะโพก, 1 = เอว, 2 = อก, 3 = คอ
  - faces ที่เลือกบนตัวปกติเก็บไว้ใน `<ชื่อ>_clothes.json` แล้วใช้ชุดเดียวกันกับทุกรูปร่าง
  - ชิ้นแรกที่ต้องการ face นั้นได้ไป (เช่น เสื้อก่อนกางเกง) จึงไม่มีสองชิ้นใช้ texture จุดเดียวกัน
  - ขอบผ้าบนลำตัว (ชายเสื้อ คอเสื้อ ขอบผ้าแถบ) ตัดตามวงแหวนของลำตัว: `build_body*.py` สร้างลำตัวก่อนเป็นวงละ 16 จุด (จุด 16k..16k+15 = วง k)
    face ระหว่างสองวงนับว่าอยู่ที่วงล่าง วงแหวนช่วงบ่าเอียงขึ้นด้านข้าง ถ้าตัดด้วยความสูงตรงๆ ขอบจะแหว่งเป็นขั้นบันได
    คอเสื้อคือวงแรกที่ weight ของ `neck` + `head` เกินครึ่ง
- **tube** (ผ้าซิ่น โสร่ง ผ้าคาดเอว เข็มขัด): ท่อที่วัดขอบนอกของสะโพกและขาทีละระดับความสูง (convex) บวกระยะห่าง แล้วตกตรงลงมา
  - วัดจากจุดที่สุ่มถี่ทั่วพื้นผิว ไม่ใช่แค่จุดยอด แต่ละวงวัดคลุมไปถึงวงข้างเคียง จึงไม่มีผิวโผล่ทะลุระหว่างวง
  - วัดรวมเสื้อและกางเกงที่ใส่อยู่ข้างใน (ไม่นับแขนเสื้อ) ผ้าซิ่นจึงคลุมชายเสื้อ และผ้าคาดเอวของตัวอ้วนอยู่นอกพุง
  - วงช่วงเอวห่างกัน 2 ซม. ผ้าจึงแนบเอว ไม่ตั้งออกมาเป็นชั้น
  - weight ได้จากผิวที่ใกล้ที่สุด ยิ่งต่ำลงยิ่งเอนไปตาม `hips` (ที่ชายผ้าเป็น 50%)
  - โสร่งมีขอบม้วนที่เอว
- **strip** (สไบ ผ้าพาดคอ ปลายผ้าขาวม้า ผ้าพาดบ่า สังวาล): แถบผ้ามีความหนา วางตามเส้นทางบนผิวที่หาด้วยการยิง ray จากหน้า หลัง และด้านบน
- เพิ่มเติม: `ring` (กำไลรอบข้อมือ/ข้อเท้า), `hat` (งอบ ผูกกับ `head`)
  - `shoe` รองเท้าผ้าใบ: ห่อเท้าด้วย convex hull แล้วดันออก 8 มม. พื้นรองเท้าแบน (ถ้าใช้ shell นิ้วเท้า low-poly จะโผล่เป็นนิ้วๆ)
  - `helmet` หมวกกันน็อกเต็มใบ: ทรงรีรอบหัวเผื่อผม คางยื่นไปด้านหน้า ขอบล่างยกขึ้นใต้ขากรรไกรแล้วลงคลุมท้ายทอย
    หน้ากากเป็นชิ้นแยก (`visor_black`) texture `helmet_white` มีแถบคู่สีดำบนหัว แถบแดงด้านข้าง หมุดบานพับ ช่องลม และขอบยางดำ

**Texture**
- ลายผ้าที่ใช้ร่วมกันอยู่ใน `clothes_tex/<ลาย>_Color/_Normal/_Roughness.png` (ทองมี `_Metalness` ด้วย) ได้แก่
  `plaid_red`, `plaid_pink`, `red_cloth`, `sin_purple`, `sin_ikat`, `sin_tinjok`, `sabai_red`, `scarf_stripe`, `straw`, `gold`,
  ผี: `ghost_sin_red`, `ghost_sin_green`, `ghost_sin_white`, `ghost_sabai_cream`, `ghost_sabai_cream_blood`, `ghost_sabai_green`, `ghost_sabai_white`,
  ผีนางรำ: `ghost_brocade_sin`, `ghost_sabai_red`, `ghost_dancer_gold` (มี `_Metalness`), `ghost_flower`, โลงศพ: `coffin_lacquer`, `coffin_wood`,
  `vans_checker`, `skate_black` (รองเท้า: u รอบเท้า v จากพื้นรองเท้าถึงขอบบน), `helmet_white`, `visor_black` (u รอบหัว v จากขอบล่างถึงกระหม่อม)
- ลายวน (tile) ทุก 0.32 ม. (`TILE`) UV เป็นหน่วยเมตร ลายจึงมีขนาดเท่ากันทุกตัว
  ส่วนผ้าซิ่นใช้ v จากชายผ้า (0) ถึงเอว (1) เพื่อให้ตีนซิ่นอยู่ที่ชายผ้าเสมอ
- texture ของ shell อยู่ข้าง .blend ชื่อ `<ชื่อ>_<ชุด>_Color/_Normal/_Roughness.png`

**ใน .blend:** ทุกชิ้นอยู่ใน collection `Clothes` ผูกกับ HumanRig ด้วย Armature modifier ชุดที่ไม่ได้ใช้ซ่อนไว้ (`hide_render`)
ใน Roblox ให้ export ทีละชุดเป็น MeshPart ละ 1 ชิ้น (1 ชิ้น = 1 SurfaceAppearance) แล้วสลับชุดด้วยสคริปต์ ส่วน Body ยังอยู่ใต้ผ้าตามเดิม

```python
exec(open(r"C:\Aunival\pump-lot-anomaly\assets\models\human_base\build_clothes.py", encoding="utf-8").read())
clothes_all()          # วาดลายผ้า เลือก faces บนตัวปกติ วาด texture แล้วใส่ชุดให้ทั้ง 16 ไฟล์ (ไม่แตะไฟล์ .blend1)
add_clothes("female")  # ฉากปัจจุบัน: สร้างทุกชุดของตัวละครใหม่ (ต้องมี human_female_clothes.json)
preview_all()          # เรนเดอร์ clothes_previews/*.png
preview_ghosts()       # เรนเดอร์ clothes_previews/ghost_*.png (เฉพาะชุดผี บนผิว SkinGhost)
```

ถ้าจะเพิ่มชุดใหม่โดยไม่แตะชุดเดิม: `add_outfits("female", ["ghost_tani"])` เติม faces ของชุดใหม่ลง `<ชื่อ>_clothes.json`
(ชุดเดิมเก็บ faces ตามที่บันทึกไว้) วาด texture เฉพาะชุดใหม่ ใส่ชุดใหม่ในทุกไฟล์ของตัวนั้น (`add_clothes(..., keep_others=True)`)
จำกัด weight 4 กระดูก แล้วบันทึกโดยใช้ path ของ texture แบบ relative (ชุดผีทำแบบนี้)
หลังเพิ่มชุด faces ที่ Roblox ตัดออกใต้ชุดเปลี่ยน ชิ้น `Skin_NN` จึงเปลี่ยนตาม: export ใหม่แล้วนำเข้าใหม่พร้อม `HumanSkinParts.luau`

**ข้อจำกัดที่ยังเหลือ**
- ผ้าซิ่นและโสร่งยาวเป็นท่อตรง เวลาก้าวขายาวๆ ขาอาจทะลุผ้า (ผ้าตามสะโพกครึ่งหนึ่ง) ยังไม่มีกระดูกผ้า
- โจงกระเบนเป็นกางเกงพองสองขา ยังไม่มีชายผ้าที่ม้วนลอดไปด้านหลัง
- คอเสื้อเป็นช่องตามแนว faces ของคอ ยังไม่มีปกที่ปั้นเป็นรูปทรง (คอวีและปกดำของเสื้อแดงเป็นแค่สีบน texture)
- ผ้าพาดคอและสไบวางแนบไปกับตัว ไม่ได้ห้อยอิสระ
- หมวกกันน็อกเผื่อที่ให้ผมทรงทั่วไป แต่ผมยาวยังห้อยออกมาใต้หมวก ผมทรงฟูอาจทะลุ ในเกมให้ซ่อน `Hair_*` ตอนใส่หมวก
- รองเท้าเป็นทรงนูนแข็งทั้งชิ้น เวลางอนิ้วเท้ามากๆ ปลายรองเท้าจะงอตามกระดูก `toe`
- งอบวางบนหัวตามความสูงของหนังศีรษะ ทรงผมที่ฟูมาก (ผมหยิกของหญิงชรา) อาจทะลุงอบ (งอบจึงมีแค่ในชุด `farmer`)
- ชุดผี: รูขาดเป็นแค่สีบน texture มองไม่ทะลุ ชายผ้าขาดเป็นริ้วจริงเฉพาะซิ่น (tube) ปลายแขนเสื้อ ขากางเกง และสไบลุ่ยแค่บน texture
- เลือดที่คอของ `ghost_headless` อยู่บนผ้าเท่านั้น ผิวคอและอกเหนือผ้าแถบยังไม่มีคราบเลือด (ต้องทำผิวชุดแยกหรือ decal)

**การวางตัวละครที่เต้น:** หันหน้าไปทางเดียวกับขบวน เว้นระยะห่าง ห้ามวางให้ชายหญิงหันก้นหรือหันหน้าเข้าหากันใกล้ๆ

- **ท่าเต้น:** จังหวะ 120 bpm (1 จังหวะ = 15 เฟรม) เท่ากันทุกตัวละคร ให้เต้นพร้อมเพลงเดียวกันได้ ความแรงของท่าลดตาม `energy`
  (คนชรา ×0.5–0.55) รูปมือ (`hand`): `relax`, `fist`, `rock` 🤘, `point`, `jeeb` (จีบ: ปลายนิ้วโป้งชนนิ้วชี้ นิ้วอื่นกางแอ่น), `wong` (ตั้งวง: มือแบนแอ่นนิ้ว)
- **ยกแขนได้ไม่เกิน 70° จากท่า A-pose (`RAISE_MAX`):** ผิวข้างอกผูกกับกระดูกแขนบางส่วน ถ้ายกสูงกว่านี้ผิวจะดันทะลุเสื้อ
  (เป็นข้อจำกัดของ linear skinning ซึ่ง Roblox ใช้แบบเดียวกัน) เสื้อจึงเว้นระยะจากผิวเพิ่มตามน้ำหนักแขนของผิวจุดนั้น (สูงสุด 6 ซม. ตรงรักแร้)
- **นิสัยของแต่ละตัว (`STYLE`):** หญิงก้าวสั้นลงและสะโพกส่ายมากขึ้น, เด็กจังหวะเร็วกว่า (×0.8) และแกว่งแขนมาก,
  คนชราก้าวสั้น (×0.6) ช้าลง (×1.35–1.4) แกว่งแขนน้อยและตัวโน้มไปหน้า
- **ทิศทาง:** ค่าในสคริปต์เขียนตามแขนขาด้านซ้าย กระดูก `.R` จะกลับเครื่องหมายแกน Z ให้เอง (ตาม `add_joint_limits.py`)
  ทุกค่าถูกจำกัดตามช่วงหมุนของข้อต่อ (`JointLimit`)
