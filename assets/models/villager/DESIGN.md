# ชาวบ้านร่างใหม่ (villager) — สเปกออกแบบ v0 (2026-11-09)

สถานะ: ร่าง v1 ชาย/หญิง + กระดูกเสร็จแล้ว (ดูหัวข้อ 10) · ภาพ `01`–`04` ทำบนร่างเดิมเพื่อทดสอบแนวทาง
ยังไม่ได้แตะไฟล์ใน `human_*` และยังไม่ได้ลองใน Roblox

## 1. แนวคิด

ปั้นร่างหลักใหม่ 2 ร่าง (ชาย / หญิง) ให้ดีตั้งแต่ต้น แล้วสร้างคนหลายแบบด้วยการ **ทาสี** เป็นหลัก
มาแทนชุดเดิม 16 ไฟล์ (5 ร่าง × ผอม/อ้วน/ท้อง) ที่ชุดเป็นชั้นผ้าซ้อนทับผิว

- **ไม่มีชั้นผ้าซ้อนทับตัว:** ผ้าที่ต้องมีทรง (กางเกงขายาวหลวม ผ้าซิ่น/โสร่ง) เป็น "ท่อนล่างแบบอื่น" ที่สลับแทนท่อนล่างเดิม ข้างในไม่มีขา จึงทะลุไม่ได้ (ภาพ `02`)
- **คนแก่ใช้ร่างเดียวกัน:** ลายหน้าแก่ + ผมหงอก + ท่า mocap คนแก่ + ย่อ ~0.92 (ภาพ `03` ใกล้ร่างคนแก่เดิมมาก)
- **สีผิวย้อมตอนเล่น** ด้วย `SurfaceAppearance.Color` (API ของ Roblox: Security None = สคริปต์ตั้งได้) ภาพ `04`

## 3. แบ่ง 3 ชิ้น + รอยต่อ

| ชิ้น | มีอะไร | รอยต่อ |
|---|---|---|
| หัว | หัว คอ หู จมูก (ปั้นรวมเป็นผิวเดียว ไม่ใช่ชิ้นแปะ) | **วงคอฐาน** (ปกเสื้อวาดบนตัวบนบังรอย) |
| ตัวบน | อก ท้อง หลัง แขน มือ | วงคอฐาน + **วงเอว** (แนวเข็มขัด) |
| ตัวล่าง | สะโพก ขา เท้า | วงเอว |

- วงคอและวงเอวมีจำนวนจุด ตำแหน่ง และน้ำหนักกระดูกเท่ากันทุกแบบ ทุกชิ้นจึงต่อกันสนิทตอนก้ม/บิด (ร่างเดิมรอยคอด้านหลังแหว่ง ภาพ `01`)
- ท่อนล่างแบบอื่นทุกแบบใช้วงเอวเดียวกัน
- ข้อตกลงเรื่องเสื้อ: ลายเสื้ออยู่บนตัวบน จบที่แนวเอว เสื้อยาวคลุมสะโพก (ม่อฮ่อมปล่อยชาย) ให้มีผ้าขาวม้า/เข็มขัดบังที่เอว หรือวาดเป็นเสื้อเหน็บ

## 4. คุณภาพที่จะปรับจากร่างเดิม (ดูภาพ `01`)

| ส่วน | ร่างเดิม | ร่างใหม่ (เป้า) |
|---|---|---|
| หัว | ไข่ 16 จุดต่อวง จมูกเป็นพีระมิดแปะ หูแปะ ไม่มีรูปหน้า | 24–32 จุดต่อวง ปั้นเบ้าตา สันคิ้ว โหนกแก้ม ริมฝีปาก คาง กราม จมูกและหูต่อกับผิว |
| ลำตัว | 16 จุดต่อวง | 24 จุด: ไหปลาร้า สะบัก อก ท้อง ก้นมีรูป |
| แขนขา | 10 จุดต่อวง | 12 จุด: ศอก เข่า ข้อเท้ามีรูป น่องและต้นแขนมีกล้ามอ่อนๆ |
| มือ | นิ้วสี่เหลี่ยม 4 จุด | นิ้ว 3 ข้อ 6 จุด ข้อนิ้วมีรูป (ท่าพนมมือ หิ้วแกลลอน จับแฮนด์ ใช้นิ้ว) |
| เท้า | นิ้วเท้า 5 นิ้วแยก | เท้าเรียบ นิ้วเท้าตื้นๆ (ส่วนใหญ่ใส่รองเท้าแตะ/บูทที่วาดลงไป) |
| จำนวน | ~2,250 tris ทั้งตัว | ~4,500–6,000 tris ทั้งตัว (หัว ~1.5k · ตัวบน ~2k · ตัวล่าง ~1.5k) |

## 5. UV และการทาสี (แต่ละชิ้นมีภาพ 1024 ของตัวเอง)

- **หัว:** หน้าได้พื้นที่ราวครึ่งภาพ (หน้าชัดกว่าเดิม: เดิมหัวได้แค่ครึ่งบนของภาพทั้งตัว) ท้ายทอยได้น้อย (ผมบัง)
- **ตัวบน:** ลำตัวหน้า/หลังใหญ่ แขน มือ (มือได้พอให้เห็นเล็บ)
- **ตัวล่าง:** ขาหน้า/หลัง เท้า
- ไม่ mirror UV (กระเป๋า กระดุม ลายผ้าไม่สมมาตร)
- ช่อง alpha ของภาพสี = ส่วนที่เป็นผิว (ย้อมด้วยสีผิว) / ส่วนที่เป็นผ้า (ไม่ย้อม) — โหมด TintMask **ต้องยืนยันใน Studio ก่อน**
- normal / roughness ใช้ร่วมกันต่อชิ้น (ริ้วรอยคนแก่อยู่ใน normal ของหัวแบบแก่)
- สีหน้า (กะพริบ ร้องไห้ ผี) = สลับเฉพาะภาพหัว

## 6. ชิ้นแยก

| ชิ้น | ติดกับ | หมายเหตุ |
|---|---|---|
| ท่อนล่าง: ขายาวหลวม | วงเอว | ขาขยายเป็นทรงกางเกง (ภาพ `02` แถว 2) |
| ท่อนล่าง: ผ้าซิ่น / โสร่ง | วงเอว | ไม่มีขาข้างใน เหลือหน้าแข้งใต้ชายผ้า (ภาพ `02` แถว 3) |
| ผม หลายทรง + ผมคนแก่ | กระดูก `head` | `build_hair.py` วัดจากหัวเอง ปรับใช้กับหัวใหม่ได้ |
| งอบ / หมวก | กระดูก `head` | |
| ผ้าขาวม้าคาดเอว | กระดูก `hips` | ชายผ้าสั้น ไม่โดนต้นขาตอนนั่ง |

## 7. ไม่อยู่ในเฟสนี้

ผี (ยังใช้ไฟล์ผีเดิม) · เด็ก · ร่างอ้วน/ผอม · ผ้าห้อย (สไบ ผ้าพาดบ่า)

## 8. ตัดสินใจแล้ว (เจ้าของโปรเจกต์ 2026-11-09)

1. **สไตล์:** ต่อจากร่างเดิม (โค้งมน low-poly หน้าวาด)
2. **ความสูง:** เท่าเดิม ชาย 1.80 / หญิง 1.68 (รถทุกคันใช้ค่าเดิมได้)
3. **หน้า:** เรียบ แล้ววาดทั้งหมด (ไม่ปั้นจมูก เบ้าตา ปาก) — หูยังเป็นก้อนเรียบๆ ติดหัวเพื่อให้ทรงหัวไม่แปลก
4. **ผู้ดูแล:** เจ้าของโปรเจกต์ (queue966) ดูแลตัวละครและหน้าเองทั้งหมด
5. **เท้า:** ไม่ปั้นนิ้วเท้า เท้าเป็นทรงรองเท้า ทุกคนใส่รองเท้า (วาดแบบรองเท้าตอนทาสี: แตะ ผ้าใบ บูท)

## 9. ลำดับงานหลังตัดสินใจ

1. ปั้นร่างชาย v1 (หัวก่อน) → ภาพหน้า/ข้าง/หลัง/โครงเส้น เทียบร่างเดิม → ปรับตามคำติ
2. ร่างหญิง v1 → เหมือนกัน
3. rig + น้ำหนักกระดูก + ตรวจแขนขาทะลุทุกท่า mocap
4. UV + ทาสีทดสอบ 3–4 คน + ท่อนล่าง 2 แบบ → ภาพ
5. ลองใน Studio: สลับภาพ ย้อมสีผิว TintMask ท่า mocap คนขับรถ
6. ค่อยวางแผนย้ายของจริงในเกม
