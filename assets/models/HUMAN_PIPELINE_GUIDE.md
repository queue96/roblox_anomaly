# คู่มือทำงานต่อ: ตัวละครมนุษย์ (สำหรับ AI หรือคนที่มารับช่วงต่อ)

ไฟล์นี้อธิบาย **วิธีทำงาน**: ทำอะไร ด้วยเครื่องมืออะไร ตรวจผลอย่างไร และเคยพลาดตรงไหน
ส่วนค่าตัวเลข ตาราง และรายการทรงผม/ชุด/ท่าอยู่ใน `HUMAN_MODELS.md` ให้อ่านคู่กัน

---

## 1. หลักคิดที่ใช้กับทุกส่วน

1. **ทุกอย่างสร้างด้วยสคริปต์ Python ใน Blender ห้ามแก้มือใน .blend**
   - ไฟล์ .blend เป็นผลลัพธ์ แก้ที่สคริปต์แล้วรันใหม่
   - ถ้าแก้มือ รอบหน้ารันสคริปต์แล้วงานจะหายหมด
2. **สร้างจากร่างกายของตัวนั้นเอง ไม่ใช้ตัวเลขตายตัว**
   - ผม ผิว และชุด วัดจากหัว ผิว และกระดูกของแต่ละตัว
   - ค่าตัวเลขเดียวจึงใช้ได้กับเด็ก ผู้ใหญ่ คนชรา และรูปร่างผอม อ้วน ท้อง
   - หน่วยความยาวคูณ `s` (ขนาดตัว เทียบกับผู้ชายผู้ใหญ่ = 1)
3. **5 ตัวละคร × รูปร่าง = 16 ไฟล์ แต่ topology ต่อตัวละครเท่ากัน**
   - ผอม อ้วน และท้อง มีจำนวนจุด face และลำดับ loop เท่ากับตัวปกติ
   - สิ่งที่ต้อง "คงที่ข้ามรูปร่าง" จึงคำนวณบนตัวปกติครั้งเดียว แล้วเก็บเป็น json ข้างไฟล์ .blend ได้แก่
     - UV ของผิว → `<ชื่อ>_uv.json`
     - faces ที่ชุดแต่ละชิ้นใช้ → `<ชื่อ>_clothes.json`
   - ทุกรูปร่างใช้ texture ชุดเดียวกัน
4. **ทุกการเปลี่ยนแปลงต้องตรวจด้วยภาพเสมอ (render แล้วเปิดดู)** และถ้าตรวจเป็นตัวเลขได้ ให้ทำตัวตรวจอัตโนมัติ
   - ตัวตรวจที่มีแล้ว: แขนขาทะลุกัน, ผิวโผล่ผ่านผ้า
   - ห้ามสรุปว่า "น่าจะได้แล้ว" โดยไม่ได้ดูผล
5. **ใส่ผลลงไฟล์จริงทีหลังสุด**
   - ระหว่างทดลองให้เรียกฟังก์ชันแบบ `save=False` แล้ว render ลงโฟลเดอร์ชั่วคราว
   - ผ่านแล้วค่อยรันฟังก์ชัน `*_all()` ที่เซฟลง 16 ไฟล์
   - ตั้ง `bpy.context.preferences.filepaths.save_version = 0` เพื่อไม่ทับไฟล์ `.blend1` ที่ commit ไว้

## 2. การรัน Blender

- Blender 5.2 (Microsoft Store) รันแบบไม่เปิดหน้าต่างผ่าน `tools/blender/run_headless.ps1` (อ่านหัวไฟล์สำหรับรูปแบบสคริปต์งาน)
  ```
  powershell -ExecutionPolicy Bypass -File tools\blender\run_headless.ps1 -Script job.py -Out <temp>\job.txt -TimeoutSec 900
  ```
  - ต้องใส่ `-ExecutionPolicy Bypass` เพราะเครื่องนี้ปิดการรันสคริปต์ PowerShell ไว้
  - สคริปต์งานต้องเขียนผลลง `$Out` และสร้างไฟล์ `$Out.done` ทุกครั้ง แม้จะเจอ error ก็ตาม (ใช้ try/except)
- **วิธีเรียกสคริปต์ของโปรเจกต์ในงาน:** ใช้ `exec(open(path, encoding="utf-8").read(), ns)` ใน namespace แยก แล้วเรียก `ns["ฟังก์ชัน"]()`
- **path ในโค้ด Python ที่สร้างผ่าน shell:** ระวัง `\a` และ `\b` ที่กลายเป็นอักขระควบคุม ให้ใช้ `/` หรือ raw string
- **งานยาว:** สร้างชุดใหม่และ export รวมราว 5–10 นาที ส่วนการตรวจทุกเฟรมของทุกตัวราว 2–3 นาที
  ให้รันเป็น background แล้วรอผล
- **export FBX บางครั้งเจอ `OSError: [Errno 22]`:** Windows ล็อกไฟล์ที่เพิ่งเขียนชั่วคราว `build_anims.fbx()` จึงลองซ้ำให้อัตโนมัติ
- **render เพื่อตรวจ:**
  - Workbench (เร็ว) ใช้ดูรูปทรง ท่าทาง และผ้ากับผิว
    - ตั้ง `color_type='OBJECT'` แล้วระบายผิวเป็นสีส้ม ผ้าเป็นสีน้ำเงิน จะเห็นจุดทะลุชัด
  - EEVEE ใช้ดู texture และ normal map
  - ภาพตัวอย่างใช้กล้อง ORTHO หลายมุม แล้วต่อภาพด้วย numpy เป็นแผ่นเดียว (ดู `preview()` ในแต่ละสคริปต์)

## 3. ลำดับ pipeline และหน้าที่ของแต่ละสคริปต์ (`assets/models/human_base/`)

```
build_variants.py   สร้างตัว + rig + รูปร่าง (ดู HUMAN_MODELS.md หัวข้อ 1–5)
 → build_hair.py     ทรงผม                     → hair_all(), preview_all()
 → build_skin.py     UV + หน้า + ริ้วรอย + ผิวผี  → skin_all(), preview_all()
 → build_clothes.py  ชุด                        → clothes_all(), preview_all()
 → build_anims.py    weight ≤ 4 + ท่าทาง + export → anims_all(), export_all(), preview_all()
ตัวตรวจ: test_self_intersection.py (แขนขาทะลุกัน), check_animation.py, check_clothes.py (ผิวโผล่ผ่านผ้า)
```
- ถ้าแก้ขั้นไหน ต้องรันขั้นนั้นและ **ทุกขั้นที่อยู่ถัดไป** ใหม่
  - ตัวอย่าง: แก้ชุด → `clothes_all()` → `anims_all()` (weight ของชุดใหม่ต้องลดเหลือ 4) → `export_all()` → ตรวจ
- `build_variants.build()` เรียกทุกขั้นต่อกันอยู่แล้ว แต่ใช้ไฟล์ json ที่สร้างไว้ก่อน (`_uv.json`, `_clothes.json`)

## 4. วิธีทำแต่ละส่วน

### 4.1 ทรงผม (`build_hair.py`)
- **กรอบหัว `Head`:** วัดจากผิวหัวของตัวนั้น
  - มุมรอบหัว `th` (0 = หน้า, 90 = ซ้ายของตัวละคร) และมุมเงย `ph`
  - ระยะถึงหนังศีรษะได้จากการยิง ray จากกลางหัว (BVH)
- **รูปทรงพื้นฐาน:**
  - `shell`: คลุมหนังศีรษะถึงแนวไรผม แล้วตกลงตามแรงโน้มถ่วง → ดันออกจากตัว → เกลี่ย → พับขอบเข้า
  - `tube` / `ball` / `ring`: หางม้า มวย และห่วง
- **ทรงใหม่:** เขียนฟังก์ชัน `st_<ชื่อ>(b)` แล้วใส่ใน `STYLES` และ `CHAR_STYLES` (ตัวแรกในลิสต์คือทรงที่เปิดไว้)
- **ผมยาวที่ผ่านตัว:** ใส่ใน `BODY_BOUND` ให้ผูกน้ำหนักตามความสูงไล่ head → neck → chest → spine → hips
- **ข้อควรระวัง:**
  - ผมบางกว่า 6–8 มม. หนังศีรษะ low-poly จะโผล่
  - ผมยาวต่ำกว่าสะโพกต้องดันออกตามทิศที่ผมห้อย ห้ามดันไปหาผิวที่ใกล้ที่สุด ไม่อย่างนั้นผมจะไปติดระหว่างขา

### 4.2 ผิว หน้า และริ้วรอย (`build_skin.py`)
- **UV:**
  - ครึ่งบนของภาพ = หัวและคอ กางแบบทรงกระบอกรอบแกนกระดูก `head`
    - u = มุมรอบหัว บิดให้หน้าได้ pixel มากขึ้น (`K_FACE`), v = ความสูง
  - ล่างซ้าย = ตัว แขน ขา, ล่างขวา = มือและเท้า (ทั้งสองส่วนใช้ smart project)
- **วาดหน้า:** วาดตรงใน (มุม, ความสูง) ของหัว ตำแหน่งตาและปากวัดจากชิ้นจมูก (`landmarks`)
- **ตัว:** rasterize สามเหลี่ยมลง UV เพื่อรู้ตำแหน่ง 3D ของแต่ละ pixel แล้ววาดตามตำแหน่งจริง (ข้อนิ้ว ข้อศอก เส้นเลือด)
- **ริ้วรอย:** วาดเป็น height map (หน่วยเมตร) แล้วแปลงเป็น normal map แบบ OpenGL (+Y ขึ้น) ตามความหนาแน่น pixel ของจุดนั้น
- **ผลลัพธ์:** แต่ละตัวมี `_Color/_Normal/_Roughness.png` และชุดผี `_Ghost_*`
  - material ใน .blend: `Skin` (ใช้จริง) กับ `SkinGhost` (สำรอง)
- **ข้อควรระวัง:** สีที่ขอบระหว่างหัวกับตัว (ครึ่งบน/ครึ่งล่าง) ต้องเท่ากัน เคยมีรอยต่อที่คอเพราะทำเงาใต้คางเลยลงไปถึงขอบ

### 4.3 เสื้อผ้า (`build_clothes.py`)
มีวิธีสร้างชิ้นผ้า 7 แบบ เลือกตามลักษณะผ้า:

| แบบ | ใช้กับ | วิธี |
|---|---|---|
| `shell` | เสื้อ กางเกง โจงกระเบน ผ้าแถบ บูท | ยก faces ของผิวขึ้นมาแล้วดันออกตาม normal ได้ UV และ weight ของผิวมาด้วย มีขอบพับเข้า |
| `tube` | ผ้าซิ่น โสร่ง ผ้าคาดเอว เข็มขัด | ทีละระดับความสูง ใช้ขอบนอก (convex) ของจุดที่สุ่มถี่ทั่วผิวและผ้าชั้นใน + ระยะห่าง แล้วตกตรงลง |
| `strip` | สไบ ผ้าพันคอ ปลายผ้าขาวม้า สังวาล | แถบมีความหนา วางตามเส้นทางบนผิว (หาด้วยการยิง ray จากหน้า หลัง และบน) |
| `ring` | กำไล | วงรอบข้อมือ/ข้อเท้า |
| `hat` / `helmet` | งอบ หมวกกันน็อก | ทรงรอบหัว ผูกกับ `head` 100% |
| `shoe` | รองเท้าผ้าใบ | convex hull ห่อเท้า (ถ้าใช้ shell นิ้วเท้าจะโผล่เป็นนิ้วๆ) |
| `sandal` | รองเท้าแตะ | พื้นแบนตามรูปฝ่าเท้า หนา ~1 ซม. + สายหูคีบรูปตัว V (ใช้ `strip`) ลาย `sandal_*` |

- **รองเท้า:** ชาวบ้าน คนแก่ ผู้หญิง ใส่รองเท้าแตะ (`sandal`), วัยรุ่นและคนแต่งตัวดีใส่ผ้าใบ (`shoe`), คนไปไร่ไปนาใส่บูทหรือเท้าเปล่า

- **ชุดใหม่:** เพิ่มใน `OUTFITS` (ลิสต์ของชิ้นผ้า) และ `CHAR_OUTFITS`
  - สีและรายละเอียดของ shell (กระดุม กระเป๋า คอวี ตะเข็บ ลายพราง ฯลฯ) อยู่ใน `FABRIC` และ `paint_shell`
  - ลายผ้าที่วนซ้ำได้ (tile) ใช้ `@pattern` ไฟล์จะอยู่ใน `clothes_tex/`
- **การเลือก faces ของ shell:**
  - เลือกตามส่วนของตัว (`torso` / `arm` / `leg` / `foot`) และตำแหน่งตามกระดูก
    - แขน 1 = ศอก, 2 = ข้อมือ; ขา 1 = เข่า, 2 = ข้อเท้า; ลำตัว `tz` 0 = สะโพก, 1 = เอว, 2 = อก, 3 = คอ
  - **ขอบบนลำตัวตัดตามวงแหวน 16 จุดของลำตัว ห้ามตัดด้วยความสูงตรงๆ** เพราะวงแหวนบ่าเอียง ขอบจะแหว่งเป็นขั้นบันได
  - ชิ้นแรกที่ต้องการ face นั้นได้ไป จึงไม่มีสองชิ้นใช้ texture จุดเดียวกัน
- **การผูก weight:**
  - shell ใช้ weight ของผิว
  - tube ไล่จาก `hips` ที่เอว ไปจนตามขาเต็มที่ที่ชายผ้า
    - ด้านนอกขาแต่ละข้างตามขาข้างนั้น ด้านหน้าและหลังไล่น้ำหนักจากขาหนึ่งไปอีกขา
    - ผ้าจึงขึงเป็นแผ่นเดียวระหว่างขา ไม่แยกเป็นขากางเกง
- **ผิวใต้เสื้อถูกซ่อนใน Roblox (ทำให้เสื้อบางได้):**
  - `hidden_faces()` = faces ใต้ shell ของชุด ลบขอบตามปากเสื้อ/ปลายแขน/ชายเสื้อออก `HIDE_KEEP` วง
  - ตอน export (`build_anims.split_skin`) ผิวถูกตัดเป็น `Body` (ไม่มีชุดไหนปิด) + `Skin_00`, `Skin_01`, … และเขียน `<ไฟล์>_skin.json` + `src/shared/HumanSkinParts.luau` ว่าชุดไหนปิดชิ้นไหน → `HumanNPC` ลบชิ้นที่ชุดที่ใส่ปิด
  - ใน .blend ยังเป็น `Body` ชิ้นเดียว (เครื่องมืออื่นใช้ชื่อนี้)
  - ห้ามดันเสื้อออกห่างผิวทั้งตัวเพื่อกันผิวทะลุอีก (เคยทำแล้วผู้ชายไหล่ใหญ่เหมือนนักอเมริกันฟุตบอล)
- **ระยะห่างพิเศษ** (`ROOM` ใช้เฉพาะ `EDGE_RINGS` วงจากปากผ้า ที่ยังเห็นผิว):
  - รักแร้: ตามน้ำหนักแขนของผิว ด้านบนไหล่ได้น้อยกว่า (`ARMPIT_TOP`)
  - ข้อศอก ข้อพับสะโพกและก้น เป้า และเข่าของกางเกงขายาว
  - ข้อเท้าในบูท
  - ชายผ้าซิ่นด้านหลังและปากชายผ้า

### 4.4 ท่าทาง (`build_anims.py`)
- **ท่าเป็นฟังก์ชัน `c_<ชื่อ>(P, t, st, s)`:**
  - `t` = 0..1 รอบลูป, `st` = นิสัยตัวละคร (`STYLE`), `s` = ขนาดตัว
  - ตั้งค่าด้วย `P.rot(bone, x, y, z)` (องศา, เขียนตามแขนขาด้านซ้าย; กระดูก `.R` จะกลับแกน Z ให้อัตโนมัติ), `P.lift()`, `arm()`, `hand()`
  - เพิ่มท่าใหม่ใส่ใน `CLIPS` ถ้าเป็นท่าเต้นที่ต้องตรงจังหวะเพลง ให้ใส่ใน `FIXED_TEMPO` ด้วย
- **ความหมายของแกนแต่ละกระดูก** อยู่หัวไฟล์ `add_joint_limits.py` ค่าจะถูกจำกัดตาม `JointLimit` ให้อัตโนมัติ
- **ข้อจำกัดที่ต้องรู้:**
  - ยกแขนเกิน ~70° จากท่า A-pose ผิวข้างอกจะดันทะลุเสื้อ (linear skinning ใน Roblox ก็เป็นแบบนี้) จึงมี `RAISE_MAX` และ `raise_max` ต่อตัวละคร
  - คนใส่ผ้าซิ่นหรือโสร่งยาวต้องใช้ `walk_skirt` / `run_skirt`
  - ท่าเต้นห้ามกางขาหรืองอเข่ามาก
- **Roblox:**
  - `limit_weights()` เหลือกระดูกไม่เกิน 4 ตัวต่อจุด
  - `export_all()` ได้ FBX หน่วย studs (1 ม. = 3.5 studs) ไฟล์ละ 1 ตัว และไฟล์ละ 1 ท่า
  - rig นี้ไม่ใช่ R15

## 5. วิธีตรวจ (ทำทุกครั้งก่อนบอกว่าเสร็จ)

1. **ภาพ:** render หลายมุม/หลายจังหวะ แล้วเปิดดูจริง
   - ถ้าเป็นเรื่องผ้ากับผิว ให้ระบายสีผิวกับผ้าคนละสีให้ตัดกัน
   - ซูมดูจุดเสี่ยง: รักแร้ เป้า เข่า ชายผ้า และหลังคอ
2. **แขนขาทะลุกัน:** `check()` ของ `test_self_intersection.py` ทุกเฟรมของทุกท่า ต้องได้ 0
3. **ผิวโผล่ผ่านผ้า:** `check_clothes.check_char(char, step=1)` ทุกชุด × ทุกท่า ต้องได้ "no skin through cloth" (ไม่นับผิวที่ถูกซ่อนใต้ชุด)
   - ถ้าเจอ ใช้ระดับจุดยอดหา vertex ที่โผล่ (ตำแหน่ง ส่วนของตัว น้ำหนักกระดูก) แล้ว render ซูมดูก่อนแก้
   - ต้องแยกให้ออกว่าโผล่จริง หรือรังสีหลุดออกทางช่องที่เปิดไว้ (ปากชายผ้า ใต้คางของหมวก)
4. **export:** นำ FBX กลับเข้า Blender เพื่อเช็ก จำนวนชิ้น, ความสูงเป็น studs, กระดูกต่อจุด ≤ 4, จำนวนเฟรมของท่า

## 6. บทเรียนจากปัญหาที่เคยเจอ (อย่าทำซ้ำ)

| อาการ | สาเหตุ | วิธีแก้ที่ใช้ |
|---|---|---|
| ริ้วรอยไม่ขึ้นเลย | ใช้ความกว้างเส้นไปคูณความเข้ม | แยกความกว้างกับความเข้มใน `Canvas.seg` |
| คอเสื้อด้านหลังแหว่งเป็นขั้น | ตัดด้วยความสูงข้ามวงแหวนที่เอียง | ตัดตามวงแหวนลำตัว (`Body.ring`, `collar`) |
| ผ้าซิ่นลอยจากเอว / สะโพกทะลุ | วัดขนาดจากจุดยอดอย่างเดียว หน้าต่างความสูงกว้างเกิน | สุ่มจุดถี่ทั่วผิว, แต่ละวงคลุมถึงวงข้างเคียง, วงช่วงเอวถี่ 2 ซม. |
| ผ้าคาดเอวจมในพุงตัวอ้วน | ไม่นับเสื้อชั้นใน | วัดรวมผิวของ shell ชั้นใน (ยกเว้นแขนเสื้อ) |
| ผ้าซิ่นบานเป็นจาน | นับแขนเสื้อที่กางออกเป็น "ชั้นใน" | นับเฉพาะ shell ที่คลุมลำตัวและขา |
| ผ้าซิ่นแยกเป็นขากางเกงตอนเดิน | ใช้ weight ของผิวที่ใกล้ที่สุด (ขาข้างเดียว) | ไล่น้ำหนักจากขาหนึ่งไปอีกขาอย่างต่อเนื่อง |
| รองเท้าเห็นนิ้วเท้า | ทำจาก shell ของเท้าที่มีนิ้วแยก | convex hull |
| ผิวโผล่ใต้รักแร้ตอนยกแขน | linear skinning บิดผิวข้างอกออกนอกผ้า | เว้นระยะตามน้ำหนักแขน + จำกัดการยกแขน |
| ยอดรักแร้หญิงชราโผล่ตลอด | ผิวจุดนั้นผูกกับแขน 100% | `fix_armpit_weights` เฉลี่ยน้ำหนักกับจุดรอบข้าง |
| ท่า export มีความยาวผิด | exporter อบเฟรมตามช่วงของ scene | ตั้ง `frame_start` / `frame_end` ตามท่าก่อน export |
| หมวกกันน็อกดูเหมือนข้าวปั้น | ทรงรีเรียบ หน้ากากสี่เหลี่ยม | คางยื่น, ขอบล่างยกใต้ขากรรไกร, หน้ากากแยกชิ้น, ลาย/ช่องลม/หมุด |

## 7. ข้อตกลงกับเจ้าของโปรเจกต์

- **ภาษาและการส่งงาน:**
  - คุยและเขียนเอกสารเป็นภาษาไทย ส่วนชื่อโค้ด ตัวแปร และ commit message เป็นภาษาอังกฤษ
  - ส่งงานเป็นไฟล์ในเครื่อง ห้ามใช้ Artifact
  - ส่งภาพตัวอย่างให้ดูทุกครั้งที่ทำเสร็จ
- **git:**
  - commit/push เฉพาะเมื่อเจ้าของสั่ง และทำบน branch งาน (ตอนนี้คือ `feature/character-hair`)
  - ไฟล์ .blend, texture, json, รูปตัวอย่าง และ FBX ใน `roblox/` commit ทั้งหมด (เจ้าของตกลงเรื่องขนาดไฟล์แล้ว)
- **ทำ ref ตามภาพ:** ภาพ ref อยู่ใน `art_refs/` เจ้าของชอบให้ทำตามภาพจริง แล้วปรับตามคำติ
- **รายงานผล:**
  - รายงานตามจริง: ตรวจอะไรแล้ว ตรวจด้วยวิธีไหน และอะไรที่ยังไม่ได้ตรวจ (เช่น ยังไม่ได้ลองใน Roblox Studio)
  - เมื่อแก้แล้วยังเหลือจุดเล็กๆ ให้บอกพร้อมเหตุผล อย่าเงียบ

## 8. งานที่ยังค้าง

- นำเข้า Roblox Studio จริง (3D Importer + Animation Editor) แล้วตรวจสเกล แกน และการเล่นท่า
- เขียนสคริปต์ฝั่งเกม:
  - สลับผม ชุด และผิวผี
  - เลือก `walk_skirt` / `run_skirt` ตามชุด
  - เล่นท่าผ่าน `AnimationController` + `Animator`
- ตรวจผมยาว (ผมผี) กับท่าทาง: ยังไม่มีตัวตรวจ ขาอาจทะลุผม
- ท่าที่ยังไม่มี: กระโดด นั่ง ตกใจ และกระดูกผม/ผ้าที่แกว่งเองได้
